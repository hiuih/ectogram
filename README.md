# Ectogram

A native macOS wrapper for [Instagram](https://www.instagram.com) built with Electron. Real dock icon, real title bar, working camera/mic, native notifications — the real Instagram in an app that feels like it belongs on your Mac.

**Unofficial, independent project.** Not made by, affiliated with, or endorsed by Meta/Instagram. It's a thin native shell around Instagram's own website — every account, photo, and DM is served by Instagram's real servers.

## Install

Download the latest `.dmg` from [Releases](../../releases), open it, and drag Ectogram to Applications. Unsigned build — first launch: right-click → Open.

## Build from source

```bash
npm install
npm run dist
```
